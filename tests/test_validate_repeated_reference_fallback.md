# Test Fixture: One Fallback, Many References

A skill that names a companion once and states its degraded path there, then goes on
referring to that companion wherever the workflow reaches it. The fallback is a fact about
the companion, not about the sentence — restating it at every mention is the duplication
this pack spent a whole plan removing.

## Step 1 — Build

Run the `cyw` skill over your own change. Where that skill is unavailable, do the
equivalent pass by hand: re-read every modified file for correctness, completeness and
consistency, and fix what is wrong.

## Step 2 — Some intervening prose

This paragraph exists to put real distance between the reference above and the one below,
so the second mention is genuinely outside the locality window rather than incidentally
inside it. Nothing here says anything about degraded paths.

More filler, for the same reason. The window is a handful of lines, so a fixture that put
the two mentions close together would pass whether or not the rule was relaxed, and would
therefore prove nothing at all.

## Step 3 — Fix

Address each finding, then run the `cyw` skill again over the fix.

## Step 4 — Gate

The phase is complete once the `cyw` skill reports nothing further.
